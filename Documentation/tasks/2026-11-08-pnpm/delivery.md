# Delivery: Replace Bun with pnpm

## Summary

Bun was removed. pnpm 12.18.0 installs packages and Node 26 runs every script, including the Postgres wait script (see ADR-005, which supersedes ADR-001).

## Changes

- `package.json`: `packageManager: "pnpm@12.18.0"`; scripts use `pnpm run`; `wait-for-postgres` runs `node ./infra/wait-for-postgres.mts`; `@chakra-ui/anatomy` declared (`^2.3.6`).
- `bun.lock` removed; `pnpm-lock.yaml` generated by pnpm; `pnpm-workspace.yaml` allows the `@swc/core` build script.
- `infra/wait-for-postgres.ts` → `.mts`, with `type ExecException`. `tsconfig.json` includes `**/*.mts`.
- `.prettierignore`: `pnpm-lock.yaml`.
- `.github/workflows/*.yaml` (5 files): `oven-sh/setup-bun` → `pnpm/action-setup@v6` before `setup-node` (`cache: 'pnpm'`, still `node-version-file: '.nvmrc'`); `bun`/`bunx` → `pnpm`/`pnpm dlx`.
- `vercel.json`: `pnpm install --frozen-lockfile`, `pnpm run build`.
- `CLAUDE.md`, `README.md`, ADR-001 status, ADR-005.

## Validation

- Acceptance criteria:
  - No `bun`/`bunx` left in code, scripts, CI or `vercel.json`: met (historical records in `Documentation/` kept).
  - `pnpm-lock.yaml` committed, no `bun.lock` or `package-lock.json`: met.
  - All checks and the suite pass locally: met.
